# 一组 EMA，帮你判断趋势、回调和关键位置

## 旁白稿｜待确认

如果图表上只能留一个指标，我会留 EMA。

不是因为它能告诉你明天涨还是跌，而是因为它能帮你把三个问题看清楚：趋势往哪边走？价格是不是离得太远？回调到关键位置后，价格有没有转强？

先说第一个作用：看趋势方向。

用 7、25、99，分别看短、中、长周期。价格从回踩后走出一段上涨，短期线先抬起，25 和 99 随后跟上。

冲高后，价格先跌回短期 EMA 下方，短期走弱；但中期 EMA 还在上行，不能因为短线回落就说中期转弱。

再看右边，价格继续下探，中期 EMA 由上行转平，再向下；价格收在它下方，中期走势也开始转弱。长期 EMA 仍向上，变化最慢，提供更长周期的背景。

短线看变化，中线看确认，长线看方向。

第二个作用：看乖离。

先看左边第一波急涨，收盘价一度比 EMA7 高出约 11.9%，价格和均线明显拉开。右边后来又冲了一次，乖离也有约 6.7%。两次加速都说明短线跑得很快；还没进场的，别只因为涨得快就追。乖离偏大，价格可能向均值回归；已经持仓，可以考虑分批止盈一部分。

再看后面，价格先跌回 EMA7 下方，继续回落后又跌破 EMA25。接下来要看价格能不能企稳、重新站上 EMA25；如果始终站不回去，回落还可能继续。

第三个作用：看均线附近，价格怎样反应。

先看这段回调。价格回落到上行的 EMA25 附近，一度下探，收盘重新回到线附近，随后继续走高。

为什么会有买盘？持仓的人看到均线附近守住，可能继续持有或加仓；等回调的人也可能把这里当作关注区域。买盘在均线附近接住卖盘，价格随后走高，支撑就来自这轮真实的买卖反应。

再看另一个例子。下行过程中，价格反弹到向下的 EMA99 附近，但收盘仍在线下。

为什么这里会有卖压？上方买入的人等价格反弹回来，可能选择离场；看空的人也可能趁反弹卖出。卖盘把价格压回均线下，之后低点继续下移，均线附近就形成了阻力。

所以，EMA 不只是看“价格在线上还是线下”。看方向时，观察短中长周期的变化；乖离过大时，留意均值回归，持仓可以考虑部分止盈；看支撑阻力时，观察价格回到均线附近后的买卖反应。

用 EMA，不是预测下一步，而是等价格走出来，再做确认。
